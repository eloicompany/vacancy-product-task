# Тестове завдання — продукт з нуля

Привіт! Оберіть одну тему і самостійно, з допомогою AI-інструментів, побудуйте робочий продукт, який запускається локально.

Як будувати, вирішуєте ви: стек, архітектура, функціонал, бібліотеки й інструменти — ваш вибір.

## Теми

1. **Онлайн-запис для малого бізнесу.** Салони, репетитори чи СТО: клієнт сам записується на вільний час.
2. **Рахунки й оплати для фрилансерів.** Фрилансер виставляє рахунок, клієнт оплачує його за посиланням.
3. **Продаж цифрових продуктів.** Автор продає курси, шаблони чи книжки, покупець отримує доступ після оплати.
4. **Служба підтримки для SaaS.** Компанія приймає звернення клієнтів і відповідає на них командою.
5. **Своя тема.** Погодьте її з рекрутером до старту.

## Що здати

1. Публічний репозиторій у вашому акаунті GitHub з усією історією комітів.
2. README з описом продукту та інструкцією запуску.
3. Посилання надішліть рекрутеру.

Реальні секрети, персональні дані й бойові платіжні ключі не використовуйте. Готовий код і шаблони дозволені, але назвіть їх у README.

## Що далі

На дзвінку ви покажете продукт і відповісте на питання про нього.

Питання щодо завдання ставте рекрутеру. Успіхів!

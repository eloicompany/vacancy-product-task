# Тестове завдання — продукт з нуля

Привіт! Оберіть одну тему і самостійно, з допомогою AI-інструментів, побудуйте робочий продукт, який запускається локально.

Що саме має робити продукт і як його побудувати, вирішуєте ви. З продуктового боку — для кого він, які в ньому функції й сценарії. З технічного — стек, архітектура, бібліотеки й інструменти.

## Теми

1. **Онлайн-запис для малого бізнесу.** Салони, репетитори чи СТО: клієнт сам записується на вільний час.
2. **Рахунки й оплати для фрилансерів.** Фрилансер виставляє рахунок, клієнт оплачує його за посиланням.
3. **Продаж цифрових продуктів.** Автор продає курси, шаблони чи книжки, покупець отримує доступ після оплати.
4. **Служба підтримки для SaaS.** Компанія приймає звернення клієнтів і відповідає на них командою.
5. **Бронювання робочих місць.** Співробітники офісу чи коворкінгу бронюють столи й переговорні.
6. **Облік складу для магазину.** Товари, залишки, надходження й продажі невеликого магазину.
7. **Замовлення в кафе.** Гість замовляє з онлайн-меню, кухня бачить і виконує замовлення.
8. **CRM для ріелтора.** Об'єкти, клієнти, покази й угоди.
9. **Оренда речей між людьми.** Люди здають в оренду інструменти, спорядження чи техніку.
10. **Доставка за підпискою.** Регулярна доставка кави, корму для тварин чи інших товарів.
11. **Квитки на події.** Організатор створює подію, глядачі купують квитки, вхід — за QR-кодом.
12. **Збір коштів.** Автор чи волонтер відкриває збір, люди донатять і бачать, на що пішли гроші.
13. **Конструктор форм і опитувань.** Створення форм, збір відповідей і їхня аналітика.
14. **Програма лояльності.** Бонуси й знижки для постійних клієнтів кав'ярні чи магазину.
15. **Сервісний центр.** Прийом техніки в ремонт, статуси й сповіщення клієнту.
16. **Майстри для дому.** Клієнт знаходить і замовляє сантехніка, електрика чи клінінг.
17. **Керування орендою житла.** Власник веде квартири, орендарів, платежі й показники лічильників.
18. **Найм персоналу.** Вакансії, кандидати й етапи відбору.
19. **Спільні витрати.** Друзі чи сусіди записують витрати й розраховуються між собою.
20. **Сервіс для фітнес-тренера.** Клієнти, програми тренувань і прогрес.

Можна запропонувати й свою тему. Погодьте її з рекрутером до старту.

## Що здати

1. Публічний репозиторій у вашому акаунті GitHub з усією історією комітів.
2. README з описом продукту та інструкцією запуску.
3. Посилання надішліть рекрутеру.

Готовий код і шаблони дозволені, але назвіть їх у README.

## Що далі

На дзвінку ви покажете продукт і відповісте на питання про нього.

Питання щодо завдання ставте рекрутеру. Успіхів!
